# Lottorito Glossary

**Document ID:** LOT-GOV-001 | **Version:** 0.1.0

| Term | Definition |
|---|---|
| Tenant | An isolated customer/organization scope within the platform |
| Partner | An external operator or system integrated with Lottorito |
| Affiliate | A publisher/partner who acquires users or customers |
| Agent | A network member with defined referral relationships and rules/access |
| Attribution | Assigning a conversion or event to an acquisition source |
| NGR | Net revenue as contractually defined by each partner; no universal formula is assumed |
| CPA | Payment based on a qualified action |
| Revenue Share | Revenue participation under a contract and versioned formula |
| Hybrid | A combination of two or more compensation models |
| Ledger | Immutable double-entry financial records |
| Journal Entry | A financial document with balanced debit/credit lines |
| Idempotency | Ensuring retries do not create duplicate effects |
| Reconciliation | Matching records and balances against partner/payment sources |
| Promotional Credit | Incentive credit with usage rules separate from commission |

## Terminology rule
Sensitive financial and API terms must have stable equivalents in both languages. Any semantic or translation change must be recorded in both versions of this glossary.
