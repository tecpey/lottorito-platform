# Lottorito English Documentation

This directory contains the official English documentation for Lottorito.

## Bilingual Synchronization Rule

Every document or change created or updated in this directory must be synchronized in the same change with its corresponding Persian version under `docs/fa/`. Both Persian and English versions are official; neither is secondary.

Official brand and logo assets are located in [`assets/logo/`](../../assets/logo/).

Until automated CI validation is implemented, reviewers must manually verify parity between both language versions for every change.
