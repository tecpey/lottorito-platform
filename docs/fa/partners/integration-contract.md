# قرارداد اتصال شرکای تجاری

**شناسه:** LOT-INT-001 | **نسخه:** 0.1.0 | **وضعیت:** پیش‌نویس؛ قرارداد واقعی RaidenBet دریافت/تأیید نشده

## اصل اتصال
هسته فقط با مدل canonical داخلی کار می‌کند. هر شریک Adapter اختصاصی دارد؛ منطق خاص شریک نباید وارد Commission Core یا Ledger شود.

## مسئولیت Adapter
اعتبارسنجی اصالت و امضا؛ دریافت رویداد و reconciliation؛ نگاشت شناسه خارجی؛ نرمال‌سازی ارز/زمان/وضعیت؛ deduplication و idempotency؛ مدیریت نسخه API؛ retry، dead-letter و replay کنترل‌شده؛ ثبت provenance و trace ID.

## رویدادهای احتمالی
ثبت‌نام، واریز، برداشت، فعالیت واجد شرایط، اصلاح NGR، برگشت و مسدودسازی. وجود و معنای هر رویداد باید از سند واقعی شریک تأیید شود.

## امنیت
TLS؛ امضای webhook یا احراز هویت توافق‌شده؛ نگهداری و چرخش امن secret خارج از Git؛ timestamp و replay protection؛ محدودیت نرخ و اندازه payload؛ عدم ثبت token یا داده حساس در log.

## وضعیت پایلوت
RaidenBet شریک پایلوت پیشنهادی است. هنوز endpoint، credential، sandbox، schema وب‌هوک یا رفتار واقعی API در مخزن تأیید نشده؛ پس اتصال عملیاتی انجام‌شده تلقی نمی‌شود.
