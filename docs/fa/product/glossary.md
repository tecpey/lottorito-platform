# واژه‌نامه رسمی Lottorito

**شناسه:** LOT-GOV-001 | **نسخه:** 0.1.0 | **وضعیت:** واژه‌نامه نگهداری‌شده؛ تعاریف ممکن است نیازمند بازبینی مالک دامنه باشند

| اصطلاح | تعریف |
|---|---|
| Tenant | محدوده مستقل مشتری/سازمان در پلتفرم |
| Partner | اپراتور یا سامانه بیرونی متصل به Lottorito |
| Affiliate | ناشر/همکار جذب‌کننده کاربر یا مشتری |
| Agent | عضو شبکه با رابطه ارجاع و سطح دسترسی/قواعد مشخص |
| Attribution | نسبت‌دادن تبدیل یا رویداد به منبع جذب |
| NGR | درآمد خالص طبق تعریف قراردادی هر شریک؛ فرمول جهانی فرض نمی‌شود |
| CPA | پرداخت مبتنی بر اقدام واجد شرایط |
| Revenue Share | سهم درآمد طبق قرارداد و فرمول نسخه‌بندی‌شده |
| Hybrid | ترکیب دو یا چند مدل پرداخت |
| Ledger | دفترکل ثبت‌های مالی تغییرناپذیر و دوطرفه |
| Journal Entry | سند مالی شامل خطوط بدهکار/بستانکار متوازن |
| Idempotency | تضمین اینکه تکرار درخواست/رویداد اثر تکراری ایجاد نکند |
| Reconciliation | تطبیق داده و مانده با منبع شریک/پرداخت |
| Promotional Credit | اعتبار تشویقی با قواعد مصرف مستقل از کمیسیون |

## قاعده واژگانی
اصطلاحات حساس مالی و API در دو زبان باید معادل ثابت داشته باشند. تغییر معنی یا ترجمه اصطلاح باید در همین سند و هر دو زبان ثبت شود.
