## محدودیت مهم
تا زمان بررسی زنده هر branch و commit، این سند فقط snapshot ثبت‌شده در تاریخ بالاست. وضعیت ممکن است تغییر کرده باشد. هیچ کد اجرایی، migration، CI موفق، اتصال API شریک، Sandbox یا Deploy را تأیید نمی‌کند.

## نقطه شروع بعدی
1. بررسی کامل PR #7: diff، تمام فایل‌ها، نظرهای بازبین، CI و اختلاف main/head.
2. تهیه inventory کامل فایل‌های `main` و شاخه PR، با تعیین محل و وضعیت هر فایل.
3. بازبینی معنایی تمام جفت‌های فارسی/انگلیسی؛ شناسایی اسناد ناقص و تکراری.
4. تکمیل LOT-001 تا LOT-006 و تعیین تصمیمات باز.
5. ثبت ADR فناوری و دیتابیس و تثبیت محدوده MVP.

## قانون ادامه
هر ایجنت باید در پایان کار همین دفتر را در صورت تغییر وضعیت به‌روزرسانی کند، همراه با Issue، PR، SHA، تست‌ها و موارد باز. اگر کاری انجام نشده یا قابل تأیید نیست، صریحاً همان را ثبت کند.
