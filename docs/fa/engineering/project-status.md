# وضعیت واقعی پروژه و نقطه ادامه کار

**شناسه:** LOT-OPS-001 | **نسخه:** 0.2.0 | **بازبینی:** ۲۰۲۶-۱۱-۲۳

## وضعیت تأییدشده
- مخزن `tecpey/lottorito-platform` روی شاخه پیش‌فرض `main` و با سطح دسترسی Public است؛ پابلیک‌بودن مطابق تصمیم فعلی مالک حفظ می‌شود.
- اتصال GitHub مجوزهای admin، maintain، push، pull و triage را گزارش کرده است.
- راهنمای `AGENTS.md` و READMEهای دوزبانه وجود دارند.
- اسناد پایه محصول، معماری کلان، کیف پول و دفترکل، واژه‌نامه و نقشه راه در مخزن وجود دارند.
- سند مدل دامنه و ERD مفهومی در شاخه `docs/domain-data-model-v1` به دو زبان ایجاد شده است؛ این سند طرح مفهومی است، نه schema اجرایی و هنوز Merge نشده است.
- برای تغییر مدل داده، PR مستقل در حال آماده‌سازی است؛ وضعیت نهایی فقط پس از مشاهده PR و CI گزارش می‌شود.

## هنوز تأیید نشده
هیچ کد اجرایی، schema دیتابیس، migration، CI workflow، کنترل خودکار همگامی زبان‌ها، اتصال API شریک، Sandbox، محاسبه مالی، پرداخت یا Deploy عملیاتی تأیید نشده است. ادعای موفقیت تست یا Deploy بدون شواهد ممنوع است.

## دستور ادامه برای هر ایجنت
1. این سند و `AGENTS.md` را بخوان.
2. اسناد مرتبط را در هر دو زبان بخوان؛ به‌ویژه `LOT-DATA-001`.
3. وضعیت واقعی شاخه‌ها، فایل‌ها، Issueها و PRها را بررسی کن.
4. پیش از ایجاد هر چیز، وجود کار مشابه را جست‌وجو کن.
5. ابهام‌ها را به پرسش یا Issue تبدیل کن؛ فرض را قانون نکن.
6. تغییرات را دوزبانه، تست‌شده و همراه شواهد تحویل بده.
7. سند مفهومی را با migration یا schema اجرایی اشتباه نگیر؛ ابتدا open decisionها و ADRها را حل کن.

## ترتیب بعدی
بازبینی LOT-DATA-001؛ پاسخ به پرسش‌های DATA-Q01 تا DATA-Q12؛ تکمیل logical ERD و data dictionary؛ ADR دیتابیس و tenant isolation؛ طراحی ledger accounting؛ قرارداد API و event envelope؛ سپس CI parity و اسکلت برنامه.

## تصمیم‌های موردنیاز مالک
ماهیت اعتبار تبلیغاتی ۱۰۰ دلاری، تعریف NGR، درصد و توزیع کمیسیون، قواعد ارتقا، سیاست برداشت، ساختار sponsor و انتقال زیرمجموعه، حوزه‌های قضایی و جزئیات API شریک.
