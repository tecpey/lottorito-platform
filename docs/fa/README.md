# مستندات فارسی Lottorito

این پوشه مرجع رسمی مستندات فارسی پروژه Lottorito است.

## قانون همگام‌سازی دوزبانه

هر سند یا تغییری که در این پوشه ایجاد یا به‌روزرسانی می‌شود، باید در همان تغییر با نسخه متناظر انگلیسی در مسیر `docs/en/` نیز هماهنگ شود. نسخه فارسی و انگلیسی هر دو رسمی هستند و هیچ‌کدام نسخه فرعی دیگری نیست.

تا زمان راه‌اندازی کنترل خودکار CI، همگامی دو نسخه باید در بازبینی هر تغییر به‌صورت دستی بررسی شود.
